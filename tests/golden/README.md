# Golden outputs

These are recorded outputs of the generators for the **fictional** demo person, used by the tests
to catch unintended changes. They are test fixtures, not examples of good writing: the cover
letter's repeated "hands-on experience at …" bullets are what the template produces today, and a
change to the wording should update these files on purpose. For output meant to be read, see
[../../samples/](../../samples/README.md).
