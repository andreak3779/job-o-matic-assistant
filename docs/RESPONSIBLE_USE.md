# Responsible use

## Who the tool serves

The tool serves the candidate. It helps one person decide whether a posting is worth applying to
and drafts documents for them to review. It does not rank or filter other people, and it is not
meant for employer-side screening. The rating exists to say "go" or "no go" on the candidate's own
application, and every rating comes with the reasons (matched skills, gaps and the rule that
applied), so the decision can be checked rather than trusted.

## What it does not do

- It does not submit applications. Every application is sent by hand.
- It does not read, scrape or automate job boards or applicant-tracking systems. Postings are saved
  by the user as files.
- It does not try to defeat applicant-tracking filters or detection of automated applications.
  Documents are written for a person to read.
- It does not invent experience. See [TRUTHFULNESS.md](TRUTHFULNESS.md).

## Employers' application policies

Some employers restrict or ban AI-assisted or automated applications. Read the posting and the
employer's policy before using any generated text, follow it, and describe honestly how a document
was prepared if you are asked.

## Protected characteristics

The tool never adds protected-characteristic or self-identification information to a document by
default and never infers it from other files. Where a posting invites applicants to self-identify,
the tool asks whether to include it for that specific posting and adds it only after an explicit yes.
Confirmation is per posting; a past yes does not carry over. This rule is written in
[CLAUDE.md](../CLAUDE.md) for every skill and generator.

## Reviewing output

Generated documents are drafts. Read each one, check every claim against what you know to be true,
and take responsibility for what you send.
