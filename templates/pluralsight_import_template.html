How this fits the pipeline

The import file holds only the entries at 100%. Save it anywhere, then run python -m jobomatic learning import <file> to see what is new (a dry run), and again with --apply to save it. The importer matches items by link, never by title, and keeps a copy of the file in the vault's imports/pluralsight/. Never edit the vault's items.yaml by hand.
